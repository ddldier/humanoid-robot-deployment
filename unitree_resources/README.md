# Unitree RL MuJoCo Lab

Unitree robot reinforcement learning project using MuJoCo physics simulator.

## Contents

This repository contains robot description files and resources for Unitree robots:

- **G1 Robot Descriptions**: Various URDF and XML files for the Unitree G1 humanoid robot
  - 23DOF and 29DOF configurations
  - Different control modes
  - Hand variants
  - MuJoCo scene files

## Robot Models

The `resource/g1_description/` directory contains:
- URDF files for different G1 configurations
- MuJoCo XML scene files
- Joint configuration data
- Robot visualization assets

## Usage

These resources can be used for:
- Reinforcement learning training
- Robot simulation
- Motion planning
- Control system development

## Related Projects

This project is related to the whole body tracking and motion control research.
